673. C. The correct answer is C (Shading): the squares stay the same size and shape, but the shading goes from white to grey to black. The squares are the same size in each figure, so size does not change. Each figure is a square, so the shape type stays the same. Each square has 4 sides, so the number of sides stays the same.

674. D. The correct answer is D (Size): the circles stay grey, but each one is larger than the one before it. Each circle is grey, so the shading stays the same. Each figure is a circle, so the shape type stays the same. None of the circles has a dot, so there is no dot position to change.

675. D. The correct answer is D (Orientation): each figure is the same white arrow, but it points in a new direction, from up to right to down. Each arrow is white, so the shading stays the same. The arrows are all the same size. Each figure shows exactly one arrow, so the number stays the same.

676. B. The correct answer is B (Shading): each figure is black, so the shading stays the same while the shape and its number of sides change. The number of sides changes from 3 to 4 to 5. The shape changes from a triangle to a square to a pentagon. The number of corners changes along with the number of sides.

677. C. The correct answer is C (a black circle): the shading repeats white, grey and black, so after grey comes black, and the shape stays a circle. A white circle starts the cycle over too early, because black must come after grey. A grey circle repeats the last figure instead of moving to the next shading. A black square has the right shading but changes the shape, which stays a circle in every figure.

678. C. The correct answer is C (a black hexagon with 2 lines): the shading goes from white to grey, so the next figure is black, while the hexagon and its 2 lines stay the same. A black hexagon with 3 lines has the right shading but adds a line, and the number of lines stays at 2. A black pentagon with 2 lines has the right shading but changes the shape, which stays a hexagon. A white hexagon with 2 lines goes back to white instead of continuing from grey to black.

679. B. The correct answer is B (a white arrow pointing left): the arrow makes a quarter turn clockwise at each step, from up to right to down, so it points left next. A white arrow pointing up would be a half turn from the last figure instead of a quarter turn. A white arrow pointing right repeats the second figure instead of continuing the turn. A white arrow pointing down repeats the last figure, as if the arrow stopped turning.

680. D. The correct answer is D (a small white triangle): the sizes repeat large, medium and small, so the figure after medium is small, and the shading stays white. A large white triangle skips the small step that comes after medium. A medium white triangle repeats the last size instead of continuing the cycle. A small black triangle has the right size but changes the shading, which stays white.

681. D. The correct answer is D (a white square with 9 dots): the counts are 1, 3, 5 and 7, which go up by 2, so the next square has 9 dots. A white circle with 9 dots has the right number of dots but changes the shape, which stays a square.

The square of four boxes with no boxes shaded removes two boxes at once instead of one.

A white circle with 3 lines and 1 dot below it has the right number of dots, but the lines should keep increasing. A white circle with 5 lines and 1 dot below it adds 2 lines instead of 1.
